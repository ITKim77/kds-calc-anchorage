# `/explain-audit` — 중학생 눈높이 해설 및 상위 10% UI 품질 감사

`project.topic`의 요구사항(*"간단하게(중학생도 이해하기 쉽게) 사용자가 피드백 받을 수 있는 웹기반 소프트웨어로 통계적으로 중간 80%는 제외하고 상위 10%에 속할 수 있는 간결하고 평범하지 않는 UI디자인"*)을 다음 기준으로 점검하십시오:

1. **중학생 눈높이 번역 체크**:
   * 부착강도($f_{bd}$), 위치계수($\eta_1$), 지름계수($\eta_2$), 선단지압력($-15d_b$), 간격계수($C_d$), 형상계수($\alpha_1$), 피복계수($\alpha_2$), 최소정착길이($15d_b$) 각각에 대해 어려운 한자어나 전문 용어만 적혀 있지 않고, **중학생이 즉시 이해할 수 있는 쉬운 일상 비유와 이유 설명**이 함께 표시되는지 확인합니다.
2. **실시간 동적 피드백 체크**:
   * 입력값이 바뀔 때 *"왜 정착길이가 늘어나거나 줄어들었는지"*(예: 불량 위치 선택 시 물주머니 현상으로 인해 필요 길이가 약 1.43배 증가함, 또는 최소정착길이 $15d_b$가 지배함)를 쉬운 문장으로 즉시 알려주는지 확인합니다.
3. **상위 10% UI 미학 체크**:
   * 불필요한 시각적 공해 없이 스위스 엔지니어링 그리드, 명확한 타이포그래피 위계, 실시간 비례 SVG 도면이 조화롭게 작동하는지 점검합니다.
